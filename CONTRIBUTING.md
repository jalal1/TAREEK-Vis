# Contributing to TAREEK-Vis

Thank you for your help with TAREEK-Vis. This page tells you what to do
before we can merge your pull request.

## Contributor License Agreement (CLA)

All pull requests need a signed CLA before we merge them. This rule applies
to every contributor and to every change, also small ones.

The CLA is in [CLA.md](CLA.md). Read it before you sign. In summary:

- You keep the copyright in your contributions.
- You give Jalal Khalil, and his successors and assigns, a broad license to
  use your contributions. This license includes the right to sublicense.
  Thus, the project can change the license of the code that you contribute.
- You confirm that you have the right to give this license. If your employer
  or university can own the code that you write, get their permission first.

You sign the CLA one time. It then applies to all your contributions.

## How to sign the CLA

1. Fork the repository and make a new branch.
2. Make a new file `licensing/consents/<your-github-username>.md`.
3. Copy the signature block from the end of [CLA.md](CLA.md) into the file.
4. Fill in all the fields. Type your full name as your signature.
5. Commit the file from your own GitHub account. Do not add other changes in
   this commit.
6. Open a pull request with the title `CLA: <your-github-username>`.

The maintainer merges the CLA pull request. After that, the maintainer can
merge your other pull requests.

Do not put a postal address, a telephone number, or other private data in
the file. The repository is public, and the file stays in the history.

If you cannot sign in public, contact the maintainer through
[jalal1.github.io](https://jalal1.github.io/) before you start.

## Pull requests

- Keep each pull request on one topic.
- Fill in the pull request template. Tick the CLA box.
- Make sure that the project builds. See the build steps in
  [README.md](README.md).
