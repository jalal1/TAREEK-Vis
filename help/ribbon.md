# Ribbon commands

## Home

| Group | Button | Use | Shortcut |
|-------|--------|-----|----------|
| Data | Open Folder | Open a run folder. | Ctrl+O |
| Data | Recent Folders | Open one of the last 5 folders. | |
| Data | Open Files | Select the network and events files one by one. | |
| Data | Load Counts | Load a traffic counts file. | Ctrl+Shift+C |
| Data | Rebuild Cache | Read the run files again and make a new cache. | |
| Playback | Play / Pause | Start or stop the playback. | Space |
| Playback | Go to Start | Go to the first time of the run. | Home |
| Playback | Go to End | Go to the last time of the run. | End |
| Playback | Speed | Set the playback speed (0.5x to 100x). | |
| Navigate | Fit to Network | Show all of the network. | F |
| Navigate | Pan | A drag only moves the map. | H |
| Navigate | Zoom In / Zoom Out | Zoom the map. | Ctrl++ / Ctrl+- |

## View

| Group | Button | Use |
|-------|--------|-----|
| Layers | Nodes, Links, Link Counts | Show or hide the layer. |
| Layers | Info Panel | Show or hide the Info page of the side panel. |
| Vehicles | All Vehicles, Private, Bus, Tram, Rail, Other Modes | Show or hide the vehicles of that type. Other Modes lists the other modes of the run. |
| Vehicle Style | Shape, Size, Color | Change how vehicles look. |
| Background Map | Background Map | Show or hide the background map. |
| Background Map | Source | Select OpenStreetMap, Satellite or Topo Map. |

## Transit

| Group | Button | Use |
|-------|--------|-----|
| Routes | Bus, Tram, Rail | Show or hide the routes of that mode. |
| Stops | Bus Stops | Show or hide the stops. |
| Style | Route Thickness | Set the line width of the routes. |

## Air

The Air tab shows only when the run has aircraft. See [Air traffic](air-traffic.md).

| Group | Button | Use |
|-------|--------|-----|
| Layers | Air Links | Show or hide the air links. Off at the start. |
| Layers | Vertiports, Trails | Show or hide the vertiport marks or the trails. |
| Height | Altitude Lift | How far an aircraft symbol moves up for its height. |
| Height | Altitude Band | Show only the aircraft in one band of height. |
| Events | Losses, Holds | Show or hide the losses of separation or the holds. |

## Analysis

| Group | Button | Use |
|-------|--------|-----|
| Heatmap | Activity Heatmap | Show the density of one activity type. |

## Scenario

| Group | Button | Use |
|-------|--------|-----|
| Selection | Selected Links | Show or hide the Selected Links page. |
| Selection | Clear Selection | Remove all links from the scenario. |
| Export | Export Scenario | Save the scenario file. |

## Export

| Group | Button | Use | Shortcut |
|-------|--------|-----|----------|
| Image | PNG | Save the map as a PNG image. | Ctrl+Shift+P |
| Image | PDF | Save the map as a PDF file. | Ctrl+P |
| Video | Record | Record a video of the playback. | Ctrl+R |
| Video | Stop | Stop the recording. | Ctrl+Shift+R |

## Help

| Group | Button | Use | Shortcut |

| Help | Keyboard Shortcuts | Show the list of shortcuts. | |
| Help | Report a Problem | Open the issue page of TAREEK-Vis on GitHub. | |

## Search box

The search box at the right of the tabs finds a link, a person or a vehicle
by its ID (Ctrl+F). See [Find a link, person or vehicle](find.md).
