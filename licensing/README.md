# Licensing records

This folder keeps the records of the rights that contributors give to
TAREEK-Vis.

## Contents

- `consents/` keeps one file for each person who signed the
  [Contributor License Agreement](../CLA.md). Each file has the name
  `<github-username>.md`. See [CONTRIBUTING.md](../CONTRIBUTING.md) for the
  steps.
- `consents/` also keeps the records of relicensing permissions. A
  relicensing permission is a statement from a past contributor that lets the
  project change the license of the code that they contributed. Give each
  file the name `relicense-<github-username>.md`.

## Rules for the records

- Record the CLA version, the date, and the GitHub username in each file.
- Do not change or delete a signed record. If a contributor signs a new CLA
  version, add a new file.
- Do not put postal addresses, telephone numbers, or private e-mail
  addresses here. This repository is public, and git keeps all history.
- Keep the full original of a permission (for example, the e-mail with its
  headers) in a private location. Put only a summary here: who gave it, the
  date, the scope, and the exact words of the permission.
